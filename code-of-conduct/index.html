CODE OF CONDUCT

KAIBYAKUに関（かか）わるすべての方（かた）に、安心（あんしん）して関（かか）わり続（つづ）けていただくための行動（こうどう）規範（きはん）です。

制定日（せいていび）：2026年（ねん）7月（がつ）5日（にち）

はじめにPURPOSE

本（ほん）規範（きはん）は、KAIBYAKU株式会社（かぶしきがいしゃ）（以下（いか）「当社（とうしゃ）」）の事業（じぎょう）活動（かつどう）に関（かか）わるすべての方（かた）が、立場（たちば）や経験（けいけん）の違（ちが）いにかかわらず、安心（あんしん）して参加（さんか）し、発言（はつげん）し、協力（きょうりょく）し合（あ）える環境（かんきょう）を保（たも）つために定（さだ）めるものです。

対象者（たいしょうしゃ）SCOPE

当社（とうしゃ）の役員（やくいん）・従業員（じゅうぎょういん）・業務（ぎょうむ）委託（いたく）・インターンをはじめ、当社（とうしゃ）が主催（しゅさい）・運営（うんえい）するイベントやコミュニティに参加（さんか）されるすべての方（かた）を対象（たいしょう）とします。

私（わたし）たちがお約束（やくそく）することOUR COMMITMENTS

  • 誠実（せいじつ）に行動（こうどう）します。事実（じじつ）を偽（いつわ）らず、できないことを「できる」と申（もう）し上（あ）げず、誤（あやま）りは速（すみ）やかに認（みと）めて正（ただ）します。
  • すべての方（かた）を、対等（たいとう）な個人（こじん）として尊重（そんちょう）します。
  • ユーザーの時間（じかん）を尊重（そんちょう）し、誤解（ごかい）を招（まね）く表現（ひょうげん）や不要（ふよう）な通知（つうち）をつくりません。

お願（ねが）いしたいことOUR REQUESTS

立場（たちば）・経験（けいけん）・専門性（せんもんせい）の違（ちが）いを尊重（そんちょう）し、お互（たが）いが安心（あんしん）して発言（はつげん）できる場（ば）づくりにご協力（きょうりょく）ください。ご意見（いけん）やご指摘（してき）は、人（ひと）に対（たい）してではなく、事柄（ことがら）に向（む）けていただくようお願（ねが）いいたします。

ハラスメント・差別（さべつ）についてHARASSMENT

性別（せいべつ）、性的（せいてき）指向（しこう）、性（せい）自認（じにん）、年齢（ねんれい）、障（しょう）がい、容姿（ようし）、人種（じんしゅ）、国籍（こくせき）、宗教（しゅうきょう）などに基（もと）づく差別的（さべつてき）な言動（げんどう）、威圧的（いあつてき）な行為（こうい）、つきまとい、歓迎（かんげい）されない性的（せいてき）な言動（げんどう）は、いずれもハラスメントに該当（がいとう）します。当社（とうしゃ）は、これらを社内外（しゃないがい）を問（と）わず一切（いっさい）許容（きょよう）しません。

禁止（きんし）行為（こうい）PROHIBITED

  • 前項（ぜんこう）のハラスメント・差別（さべつ）に該当（がいとう）する言動（げんどう）
  • 他者（たしゃ）の個人（こじん）情報（じょうほう）や機密（きみつ）情報（じょうほう）を、本人（ほんにん）の同意（どうい）なく取得（しゅとく）・公開（こうかい）する行為（こうい）
  • 法令（ほうれい）または公序良俗（こうじょりょうぞく）に反（はん）する行為（こうい）
  • その他（た）、当社（とうしゃ）が本（ほん）規範（きはん）の趣旨（しゅし）に照（て）らして不適切（ふてきせつ）と判断（はんだん）する行為（こうい）

相談（そうだん）・通報（つうほう）窓口（まどぐち）REPORTING

本（ほん）規範（きはん）に反（はん）する行為（こうい）を見（み）聞（き）きされた場合（ばあい）や、ご自身（じしん）の判断（はんだん）に迷（まよ）われる場合（ばあい）は、お問（と）い合（あ）わせ窓口（まどぐち）までご相談（そうだん）ください。ご相談（そうだん）・通報（つうほう）を理由（りゆう）として、不利益（ふりえき）な取（と）り扱（あつか）いを受（う）けることは一切（いっさい）ありません。ご相談（そうだん）いただいた方（かた）のプライバシーは、厳重（げんじゅう）に保護（ほご）いたします。

違反（いはん）への対応（たいおう）ENFORCEMENT

本（ほん）規範（きはん）に反（はん）する行為（こうい）が確認（かくにん）された場合（ばあい）、当社（とうしゃ）は、注意（ちゅうい）・警告（けいこく）、参加（さんか）のお断（ことわ）り、契約（けいやく）の解除（かいじょ）など、状況（じょうきょう）に応（おう）じた対応（たいおう）を行（おこな）います。

さいごにCLOSING

本（ほん）規範（きはん）は、罰（ばっ）するためではなく、誰（だれ）もが安心（あんしん）して「好（す）き」を語（かた）り、つくり続（つづ）けられる場（ば）を守（まも）るためにあります。ご理解（りかい）とご協力（きょうりょく）を、よろしくお願（ねが）いいたします。
